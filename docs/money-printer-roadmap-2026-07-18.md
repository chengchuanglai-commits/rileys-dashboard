## 三、印钞机的诚实方程

```
印钞 = (β + 杠杆增益 + α) × 本金 × 时间 − 执行成本 − 行为损耗
```

| 项 | 现值 | 天花板与依据 |
|---|---|---|
| β | ~10-14%/年 | 定投QQQ,已在真钱 |
| 杠杆增益 | +8-11pp | lev回测CAGR~25%,paper前向验证中(正经历第一次真回撤考验) |
| α | 未定 | hds gate 8月初裁决;即使PASS预期会衰减,容量有限($500/仓的小盘) |
| **本金** | **~$1,000真钱** | **音量旋钮。25%CAGR×$2k=$500/年;×$50k=$12,500/年。策略已快到瓶颈,本金才是下一个杠杆** |
| 时间 | 6周 | 25%CAGR复利10年=9.3倍 |
| 执行成本 | 已治理 | 零佣金券商+低换手+API成本$70→$4/月 |
| 行为损耗 | ≈0 | 系统自动+Riley只批准=已工程化消除 |

**残酷而解放的真相**:六周排除法之后,"策略空间"里能挖的大头已经挖到了——**杠杆指数(0.91)+卫星(0.94)大概率就是我们能稳定拿到的上限区间**。往后每一分强求α的努力,边际收益都远小于:①把本金做大(KineticKit/尤加利的现金流喂进来)②让时间复利。**印钞机不是一个策略,是[已验证的结构 × 更大的本金 × 更长的时间]。**
